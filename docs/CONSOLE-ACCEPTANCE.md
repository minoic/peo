Confirming UI logout closed all tracked sockets, removed the local token, and made the old JWT return 401 from both `/auth/me` and terminal-ticket creation. Only connection states were recorded, never socket URLs or credentials.

Revoking its separate final test JWT through the API also caused the browser to return to login and clear its token. That JWT was deleted. Sanitized browser evidence is in ignored `.cache/console-acceptance/ui-results.json`.
- Real Wings file operations covered list/read/write, empty text file creation and readback, rename, copy, chmod and archive creation. The browser saved and re-read `PEO browser acceptance: saved through Flutter and Wings.`.
- Independent real API streaming test: 8 MiB slow upload and download completed with matching SHA; API-canceled upload left no partial file; API-canceled download completed without leaving the stream hung. ## Local Runtime and Recovery

- Local `pterodactyl/deploy/.env` is ignored and contains `PEO_PANEL_IMAGE=peo-console-acceptance:local` and `PEO_PANEL_APP_URL=http://192.168.2.208:8088`. Compose defaults remain the published image tag and `http://localhost:8088`. To restore the published image locally, change the ignored image override to `minoic/peo:panel-2.0.0-beta.2-peo.1` and recreate only the Panel service; keep the APP_URL override while this WSL Wings node uses the canonical LAN URL.
- To build and publish a new Panel image containing current extension sources, run from repository root: `docker build -f pterodactyl/deploy/Dockerfile.panel -t minoic/peo:panel-2.0.0-beta.2-peo.2 .` then `docker push minoic/peo:panel-2.0.0-beta.2-peo.2`. No image was pushed during acceptance.
- After publishing that tag, select it using `PEO_PANEL_IMAGE=minoic/peo:panel-2.0.0-beta.2-peo.2` and recreate the Panel service. Keep the canonical `PEO_PANEL_APP_URL` setting for this WSL test node. The default Compose tag remains `.1` as requested.
- PEO `PterodactylHostname` now matches the canonical local Panel URL and ConsoleOrigins remains `http://localhost:5173`. Previous local settings are backed up under ignored `.cache/console-acceptance/original-settings.json`; restore via local admin Settings API only if returning this development instance to its prior configuration. Do not copy the secret into reports or shell history.

To return to normal development, stop the process serving port 8080 and start `server/cmd/peo` from the IDE with the same local proxy exclusions if needed.
